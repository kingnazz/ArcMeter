# ArcMeter v0.4.0

ArcMeter now shows local model availability alongside tool activity, with token
telemetry labeled by its source rather than presumed inference routing.

- Discover oMLX, Ollama and LM Studio through configurable loopback endpoints.
  View model inventory, loaded state and authoritative context metadata.
- Import oMLX hourly input, output, cached-token and request counters from its
  read-only usage database. Repeated scans are idempotent, and growing buckets
  update their existing records. Unchanged history replay skips unnecessary writes.
- Keep local runtime telemetry separate from tool telemetry. Codex, Claude,
  Gemini and Grok routing remains unknown; source totals may overlap. No local
  workload percentage, automatic subtraction or cross-source deduplication occurs.
- Use the Local Models view, recent Overview activity, telemetry-layer Activity
  filters, Insights explanations, endpoint settings and local runtime tray summary.
- Improve readability, light/dark/system appearance and narrow layouts while
  preserving existing usage, cache, quota, session and sync workflows.
- Reject path-shaped model metadata at ingestion and both sync boundaries, and
  preserve accepted long model IDs exactly. Runtime inventory and observations
  remain local; no prompt, response or raw application-log capture is added.

## Validation and remaining acceptance

The feature checkpoint passed 41 frontend tests, 130 Windows native tests and
131 macOS native tests, plus formatting, Clippy and both native production builds.
The release revision is validated again before publication.

Live Qwen/oMLX acceptance on the user's Mac remains outstanding, including
simultaneous Codex-to-oMLX routing, live counter growth, model unload/reload,
native UI/tray responsiveness and restart/redetection. Automated fixtures and
loopback tests cover these state and accounting rules but do not certify that
live installation. See [the acceptance report](../ACCEPTANCE_PR2.md).

## Installation and updates

Windows x64 uses the NSIS installer. macOS has separate Apple Silicon and Intel
installers; those apps retain the project's existing ad-hoc signing strategy and
are not Apple Developer ID signed or notarized. Updater artifacts use ArcMeter's
existing updater signing key. See [Mac installation](../MAC_INSTALL.md) and
[signed updates](../UPDATES.md).

SQLite migration 7 adds local runtime tables without rebuilding existing usage
history. Upgrade other ArcMeter devices before comparing Sessions: older clients
do not know to exclude hourly runtime aggregates from session grouping.
