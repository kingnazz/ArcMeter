# ArcMeter v0.5.1

ArcMeter now recovers cleanly when a cloud sync session expires or is revoked.

- Rejected refresh credentials are removed from the operating system credential
  store, and the account switches to signed out instead of retrying the same token.
- Settings → Sync & account shows the sign-in form and explains that signing in
  again will resume cloud sync.
- Temporary network failures and server outages preserve the saved session.
- Concurrent refreshes share the rotated credentials safely.
- Error notifications use an alert icon and error styling; successful operations
  retain the checkmark.

This patch preserves the v0.5.0 workspace and features. No database migration or
account configuration change is required. Access and refresh tokens remain in
native memory and Windows Credential Manager or macOS Keychain.

Install through ArcMeter's signed updater or use the Windows x64, Apple Silicon,
or Intel Mac installer. macOS bundles retain the existing ad-hoc signing strategy
and are not Apple Developer ID signed or notarized.
