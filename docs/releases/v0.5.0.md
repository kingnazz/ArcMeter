# ArcMeter v0.5.0

ArcMeter has a redesigned desktop workspace for measured AI usage, sessions,
quotas and local runtimes. Usage and trends lead the Overview, with fresh quota
risks surfaced above the headline metrics.

- Navigate through a grouped Monitor, Analyze and System sidebar, with a compact
  icon rail at narrow widths.
- Read telemetry through a restrained dark, light or system theme, consistent
  surfaces, clearer type and aligned numerical values.
- Explore responsive trend charts with exact values on hover or keyboard focus.
  Arrow keys, Home and End move between samples.
- Scan denser Activity rows with explicit runtime, tool and unknown-routing
  labels, sticky filters and useful empty states.
- Compare session volume, duration, event counts and cache counters; open the
  detail inspector without losing keyboard focus.
- Review reachable local runtimes, loaded models and available measured history
  separately. Configure endpoints with immediate loopback validation.
- Use focused preferences for General, Appearance, Collection, Providers,
  Local Models, Sync and account, Privacy, and Updates.
- Resize the desktop window down to 800px. Reduced-motion preferences disable
  interface animations.

## Telemetry and upgrade compatibility

The v0.4.0 collectors, SQLite schema, pricing rules, sync boundaries and privacy
protections are unchanged. Tool routing remains unknown unless established by a
source. Local runtime and tool counts can overlap; this release adds no automatic
subtraction, inferred routing or cross-source deduplication.

No runtime dependency is added. Development sample, loading and error scenarios
are explicitly labeled and excluded from production builds.

## Installation and updates

Installers are provided for Windows x64, Apple Silicon Macs and Intel Macs.
macOS bundles retain the project's ad-hoc signing strategy and are not Apple
Developer ID signed or notarized. Updater archives use the existing ArcMeter
signing key. See [Mac installation](../MAC_INSTALL.md) and
[signed updates](../UPDATES.md).

Live oMLX and Codex routing acceptance on the user's Mac Studio remains a
separate manual check; see [the local-model acceptance report](../ACCEPTANCE_PR2.md).
